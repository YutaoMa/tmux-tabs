Token bucket

A bucket holds up to capacity tokens and regains them at a fixed rate. Each request removes one token; when the bucket is empty the request is rejected until the next refill tick.

Idle time must not accrue credit forever:
refill must saturate at capacity, never accumulate past it. A bucket left idle for an hour should still release only one full burst. 

fn refill(&mut self, now: Instant) {
    self.tokens = (self.tokens + self.earned(now))
        .min(self.capacity);
}
